Tools

Tools for seeing the structure before commissioning the work.

The tools on this page help you orient a system, recognise whether a recurring problem may be structural, and understand the classification system behind the practice. They are not substitutes for a bounded diagnostic engagement.

available now

The 60-Second Structural Scan

Available now Free

Four questions that help expose what a system is for, what it is actually organised around, which rules govern it, and where the failure appears. Purpose → Primitive → Rules → Failure.

Use it when the same problem keeps returning and the cause is unclear. The scan does not diagnose the system; it helps you see whether there is enough structural signal to investigate further.

Diagnostic Taxonomy

Nine failure classes and 54 subtypes used to classify recurring structural failure. The taxonomy contains the inclusion, exclusion, refusal, and corrective logic behind the diagnostic system.
